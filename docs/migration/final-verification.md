## 本轮新增验收重点

- 双客户并发预约同一人员时段仅一成功；无技能/区域/排班或有请假不可约；改期失败保留旧占位。
- 绑定工作台不能将未付款订单误转为已付款；未绑定账号不能读私有照片；存储拒绝伪造图片与路径穿越，事务回滚移除新文件。
- 部分退款累计舍入至净额，重复退款回调不重复结算；伪造商户退款不改变订单。
- 价格规则不能借用其他租户条目，失败整单回滚；共享旧区域编辑不改变其他服务价格。
- 官网草稿不公开、推荐所属租户校验、危险 URL 拒绝、发布版本检查；小程序忽略旧时段/旧报价响应并阻止重复提交。

复现命令：后端见 [runbook](runbook.md)，小程序运行 `node tools/miniapp/check.cjs`。本轮私有照片变量、分站点发布目录、数据库升级及操作入口见[部署说明](../deployment/README.md)和[运营手册](../deployment/operations.md)。

菜单升级 V003 在全新初始化后重复执行，验证仅保留四条对应授权。H2 运行使用 `NON_KEYWORDS=VALUE` 适配上游字典字段，该本地选项不加入 MySQL 生产连接串。
