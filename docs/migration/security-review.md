# 活跃模块安全检查

范围：默认启用的 system、infra、pay、mp、homemaking 及前端身份流程。保留但未启用的可选模块未做完整安全认证。

| 检查面 | 已实现的约束 | 验证 |
| --- | --- | --- |
| 上传与下载 | 上传需认证；内容识别限制 JPEG/PNG/GIF/WebP/PDF、1–16 MB；服务端生成租户/UUID 路径；下载核对当前租户文件元数据；直传/预签名入口关闭 | 匿名 app/admin 上传 HTTP 401；实现检查 |
| 租户隔离 | 家政查询强制 tenant_id；客户访问检查 Customer + tenant relation 和对象所属客户；缺失租户失败关闭；总部平台设置仅租户 1 | API 伪造租户 403、缺租户 400；跨租户服务/SKU/地址/订单回归通过 |
| 支付权限 | 所属 userId 与 userType 双重匹配；无主订单拒绝；家政支付必须经过服务器微信身份/渠道绑定 | 4 项支付权限回归通过 |
| 支付通知 | pay 模块验签后持久化；业务回调从支付记录取得租户，核验商户单号/金额/身份/成功状态；取消后到账进入退款处理 | 实现检查；真实渠道未验收 |
| 微信身份 | 固定官方 HTTPS 接口；服务端交换 code；UnionID 按开放平台隔离；禁止冲突合并；MP state 单次消费且绑定租户/AppID；HttpOnly/Secure/SameSite cookie | 5 项身份映射回归；真实公众号 OAuth 待验收 |
| 匿名接口 | 仅公开品牌、服务目录、登录交换和必要回调；预约/地址/订单/手机号绑定需客户身份；登录入口频控 | 后台身份冒充客户 HTTP 403；代码检查 |
| 密钥与配置 | 启用配置移除上游演示凭据；DB/Redis/加密 key 环境注入；管理员锁定占位；无固定验证码/模拟登录；禁止记住登录密码 | 配置检查、正常登录检查 |
| 敏感日志 | 默认不持久化请求正文；开发日志仅记路径/耗时；脱敏失败不记录原文；频控切面不打印实参；身份外部请求异常不回传凭据 URL | 实现检查 |
| 通知 | 事务 outbox、唯一去重键、客户全局锁、发送前预占频控额度；不确定结果停止自动发送 | 9 项规则回归；服务商送达待验收 |

文件默认私有，品牌图片应使用专门发布的 HTTPS 静态资源；不要通过开放整个上传桶来解决图片预览。启用本地文件存储时，避免额外 Web 静态映射绕过受控下载接口。

支付/公众号/短信等上游渠道管理仍涉及数据库内的私有配置。部署需限制运维权限、数据库与备份访问、使用磁盘/数据库加密和密钥管理，并在导入自己的配置后执行泄漏检查。本次没有生产凭据，不声称已完成生产密钥轮换。

本地验收仅在回环地址使用隔离数据库和随机 Redis 密码；用于测试的 admin 密码及关闭验证码参数没有进入仓库。没有修改原数据库，也没有发送实际通知、付款或退款。
