# 安全边界与维护

适用于默认启用的 system、infra、pay、mp、homemaking。可选模块保留源码，启用前须单独检查权限、配置、依赖和业务约束。凭据扫描方法与已知历史风险见[安全工具说明](../../tools/security/README.md)。

| 功能 | 应持续保持的约束 |
| --- | --- |
| 租户与客户 | 家政查询强制租户条件；客户访问还需核验 Customer + tenant relation 和对象归属；缺租户失败关闭；平台设置仅总部可改 |
| 文件 | 上传需认证与内容识别；服务端生成路径；下载检查文件归属；直传和预签名入口关闭 |
| 履约照片 | JPEG/PNG ≤5 MB，限制像素并重新编码去除 EXIF；保存在私有持久目录，由授权订单成员下载；响应使用 no-store/nosniff |
| 支付与退款 | 支付身份匹配 userId 和 userType；渠道先验签落库，业务回调从支付记录获取租户，核验商户单号、金额和状态；重复通知不重复入账 |
| 微信身份 | 服务端交换 code；UnionID 按开放平台隔离；禁止冲突合并；公众号 state 单次消费且绑定租户/AppID，使用安全 cookie |
| 匿名接口 | 仅开放品牌、目录、登录交换及必要回调；预约、地址、订单、手机号绑定需要客户身份，登录频控 |
| 官网 | 已验证域名识别租户，仅返回发布版本；普通文本渲染，限制链接协议并检查推荐内容所属租户；服务端执行功能开关 |
| 运营与履约 | 配置检查版本；人员账号只绑定同租户唯一档案；预约检查技能、区域、班次、请假；事务、行锁及唯一占位约束控制并发 |
| 通知 | 事务消息表、唯一去重键、客户锁和发送前频控额度；结果不确定时停止自动重发；短信兜底受三级规则约束 |
| 日志与凭据 | 不记录登录密码、令牌、外部请求中的密钥或敏感正文；真实值使用私有环境配置；浏览器不保存登录密码 |

品牌图片使用专门发布的静态资源。不要开放整个上传桶，或把私有照片目录映射到 Nginx `root`/`alias`。数据库和照片目录须同步备份、恢复。

支付、公众号、短信等渠道配置可能包含数据库内的私有值，应限制数据库和备份访问权限，并使用适当的存储加密及密钥管理。扫描通过不等于凭据已失效或生产环境已完成轮换。新增环境变量必须同步[模板和替换清单](../deployment/environment-variables.md)。
